CASE STUDY 02 · Water Neutrality

AI-Assisted Automation of Water Potential Calculations

Challenge

Water-potential assessment across a large number of water-harvesting structures involved repetitive structure-level calculations and multiple variables such as rainfall, catchment characteristics, dimensions, storage potential and other project-specific parameters.

As the number of structures increased, there was an opportunity to improve the efficiency, consistency and scalability of the calculations.

My Professional Contribution

  • Developed an Excel-based VBA automation solution using AI-assisted coding to streamline repetitive water-potential calculations.
  • The solution enabled multiple water structures to be evaluated within a single consolidated workbook, rather than relying on repetitive standalone calculations.
  • It was designed to improve:
  • Consistency across structure-level calculations.
  • Handling of multiple structures within one analytical environment.
  • Recalculation following changes in underlying parameters.
  • Efficiency of recurring analytical activities.
  • Scalability for larger water-project datasets.

Outcome

The automated solution reduced the work-hours required for water-potential calculations by approximately 70%, significantly reducing repetitive manual effort while improving the efficiency and scalability of structure-level assessments
